# maneeshkrsingh.github.io

Source for the personal academic website of **Maneesh Kumar Singh** — https://maneeshkrsingh.github.io

Plain static HTML served by GitHub Pages (no build step; `.nojekyll` disables Jekyll).

| File | Page |
|------|------|
| `index.html` | Home |
| `research.html` | Research |
| `publications.html` | Publications |
| `team.html` | Lab (CompProb Lab: students, PhD openings) |
| `teaching.html` | Teaching |
| `cv.html` / `cv.pdf` | Short CV / full CV |
| `assets/css/style.css` | Shared stylesheet for every page |

To preview locally: `python3 -m http.server` and open http://localhost:8000.
